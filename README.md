# 🗾 白地図手帳 - BlankMap Studio

**白地図手帳 (BlankMap Studio)** は、旅や日常の「行った場所」や「行きたい場所」を白地図上に目的別（温泉、宿、グルメ、観光地など）に記録・保存し、出発点からの行き方や所要時間をスマートに検索・表示できるWeb＆Android対応アプリケーションです。

- **GitHub リポジトリ**: [https://github.com/chot-ap/CustomizableBlankMap](https://github.com/chot-ap/CustomizableBlankMap)
- **Web / PWA 公開URL (GitHub Pages)**: [https://chot-ap.github.io/CustomizableBlankMap/](https://chot-ap.github.io/CustomizableBlankMap/)

---

## ✨ 主な機能

1. **目的別（カテゴリ別）マップ機能**
   - 「♨️ 温泉・サウナ」「🏨 宿・ホテル」「🍴 レストラン・名物」「🏯 観光地・史跡」「🚗 絶景・自然・ドライブ」などの目的ごとに地図を整理。
   - 独自の目的（カテゴリ名、絵文字アイコン、テーマカラー）を自由に追加・編集可能。
   - 上部のカテゴリピルで、目的ごとの白地図にワンクリックで切り替え・フィルタリング。

2. **「行った場所」と「行きたい場所」の管理**
   - 地図上をクリック、または上部の検索バーからスポットを即座にピン留め。
   - 状態（✅ 行った場所 / ⭐ 行きたい場所）、日付、評価（星）、メモ、写真URLを記録。
   - 目的の色とステータスに応じた美しいカスタムマーカーで地図上に表示。

3. **出発点からのルート・所要時間検索**
   - 出発地点を「現在地」「地図上をクリック」「登録スポット」から自由に指定。
   - 移動手段（🚗 車 / 🚶 徒歩 / 🚲 自転車）を切り替えて、目的地までのルート・予想所要時間・総移動距離を計算。
   - 地図上に洗練されたネオンルートラインを描画し、フローティング案内カードで詳細を表示。

4. **美しい白地図スタイルの切り替え**
   - **国土地理院 白地図**: 日本の海岸線と境界線をミニマルに表現した本格的な白地図。
   - **CartoDB ライト白地図**: 淡色でスタイリッシュなグローバル白地図。
   - **国土地理院 淡色地図** & **標準地図 (OSM)**: 必要に応じて詳細地図にも切り替え可能。

5. **データ保存・バックアップ**
   - ブラウザの LocalStorage に自動保存（リロードしてもデータは保持されます）。
   - JSONファイルによるバックアップダウンロード（エクスポート）と復元（インポート）。
   - 地図の画像保存・印刷機能（カメラボタンから白地図をすっきり印刷・PDF/画像化）。

## 🚀 起動方法

### 方法1: `start.bat` をダブルクリック（おすすめ）
フォルダ内の `start.bat` をダブルクリックするだけで、ローカルサーバーが起動し、自動的にブラウザでアプリが開きます。

### 方法2: コマンドラインから起動
本フォルダで以下のコマンドを実行し、ブラウザで [http://localhost:5173](http://localhost:5173) にアクセスしてください。

```bash
python -m http.server 5173
```

## 📱 Androidアプリとしてインストールして使う方法 (PWA)

本アプリは **PWA（Progressive Web App）** に対応しており、Androidスマホやタブレットでネイティブアプリ同様にホーム画面から全画面で起動できます。

### 手順
1. スマホの **Google Chrome** などのブラウザで本アプリのURL（ローカルネットワークIPまたはデプロイ先URL）にアクセスします。
2. 画面上部に表示される「**アプリ保存**」ボタンをタップ、またはブラウザ右上のメニュー（縦の3点アイコン `⋮`）をタップします。
3. メニューから「**アプリをインストール**」または「**ホーム画面に追加**」を選択します。
4. ホーム画面に「**白地図手帳**」のアプリアイコンが追加されます。
5. アイコンをタップすると、ブラウザのアドレスバーが表示されない**完全な全画面アプリ**として起動し、いつでも快適に記録・閲覧できます。

## 🛠️ 使用技術
- **PWA (Progressive Web App)**: Web App Manifest / Service Worker
- **HTML5 / Vanilla CSS3 / Vanilla JavaScript (ESModules)**
- **Leaflet.js** (地図レンダリング)
- **国土地理院タイル / CartoDB** (白地図タイル)
- **OSRM (Open Source Routing Machine) API** (経路探索・所要時間計算)
- **OpenStreetMap Nominatim API** (住所・施設検索)
- **FontAwesome 6 & Google Fonts (Outfit / Noto Sans JP)**
